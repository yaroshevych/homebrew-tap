# Homebrew tap

Homebrew formulas for applications by [yaroshevych](https://github.com/yaroshevych).

| Application | Description | Install |
| --- | --- | --- |
| [Bypass](https://github.com/yaroshevych/bypass) | Terminal secrets manager for KeePass vaults | `brew install yaroshevych/tap/bypass` |

Bypass supports macOS and Linux on Apple silicon/ARM64 and Intel/AMD64. Its formula installs prebuilt release archives with pinned checksums.

Run `brew upgrade bypass` to update or `brew uninstall bypass` to remove it. Report application issues in the [Bypass repository](https://github.com/yaroshevych/bypass/issues), and formula issues in this tap.
